Linuxのマウント｜ディスクの中身を「/」につなぐ

保存したファイルを、Linuxの「/」から使えるようにするのがマウント。ro / rwは、そこへの書き込みを許すかどうかの違いです。

2026-11-15 · 新卒〜3年目SE · 動く図解

1. まず結論：ディスクの中身をつなぐ

マウントとは、保存装置などにあるファイルシステムをLinuxのディレクトリ階層の特定の場所から見えるようにする操作です。/は階層の一番上です。

なぜ必要？ Linuxはファイルを一つのディレクトリ階層で扱います。別のディスク上にあるファイルも、その階層の中に組み込めるようにする必要があるからです。

2. 図に登場する言葉

保存装置
SSDなど、データを保存する機器。
パーティション
保存装置を区切った領域。例として/dev/sda1が使われることがあります。
ファイルシステム
保存領域にファイル名・フォルダ・データを整理する仕組み。例：ext4。
ディレクトリ
ファイルを階層的に整理する場所。/etc、/varなど。
マウントポイント
ファイルシステムを接続して見せるディレクトリの場所。
ルートファイルシステム
Linuxのディレクトリ階層の最上位である/として利用するファイルシステム。
ro / rw
roは読み取り専用、rwは読み書き可能を意味するマウント条件。
再マウント
接続先は変えず、マウント済みのファイルシステムの条件を変更する操作。

3. ファイルを使えるまでの順番

① 保存ディスクなどの領域にはファイルシステムが作られています。
② 接続Linuxがそのファイルシステムを/などの場所にマウントします。
③ ro / rw読み取り専用(ro)ならそのファイルシステムへの書き込みを制限します。
④ 再マウント必要なら同じマウントポイントのままrwなどへ条件を変更します。

5. コマンドで実際の状態を見る

# 現在の/のマウント元とオプションを調べる
findmnt -no SOURCE,FSTYPE,OPTIONS /
# 全体のマウントを確認する
findmnt / 
# （保守時のみ）/を読み書き可能で再マウントする例
sudo mount -o remount,rw /

出力のどこを見る？

SOURCEはマウント元、FSTYPEはファイルシステム種類、OPTIONSは適用オプションです。roなら読み取り専用、rwなら読み書き可能を表します。再マウントは既存システムの状態を変更するため、保守手順を確認してから実行してください。

出力はOSや設定によって異なります。上記はコマンド例であり、実機実行結果の転載ではありません。

6. よくある誤解

マウント＝ファイルをコピーする？
いいえ。別の場所へ複製せず、ディレクトリ階層に接続します。
roなら読み取りもできない？
いいえ。読み取り専用とは書き込みを許可しないことです。
起動時は必ずro？
いいえ。起動設定・ディストリビューション・ファイルシステムによって変わります。roは整合性確認を安全に行うために使われることがあります。

7. 3問で理解を確認

Q1. /dev/sda1と/は同じ意味？

答え：違います。前者はデバイス等を表す名前、後者はLinuxのルートディレクトリです。

Q2. roのとき、ファイルを読むことは可能？

答え：可能です。roは読み取り専用で、書き込みを制限します。

Q3. mount -o remount,rw / は別のディスクに交換する？

答え：いいえ。現在/にマウント済みのファイルシステムのオプションを変更しようとします。
