SECURITY / LOCATION DATA

なぜスマホの位置情報が、海外で売買されるのか

アプリが取得した位置情報は、広告・分析などの仕組みを経由して外部へ提供されることがある。氏名がなくても、同じ端末の移動履歴は個人の特定につながり得る。

01 / 報道で分かったこと

自衛隊施設の出入りが追跡できる可能性

2026年11月16日付の日本経済新聞は、海外で流通するスマホ位置情報の分析から、自衛隊施設に関係する端末の移動記録が見つかったと報じた。

4,000万超日経が分析した端末IDの規模
304施設位置情報が確認された自衛隊関連施設
1万超施設に関係するスマホIDの報道上の規模

SOURCE / 日本経済新聞 2026.11.16 朝刊1面

重要：「1万超のID＝1万超の自衛隊員」ではない。出入り業者・訪問者などの端末もあり得る。自衛隊の内部ネットワークが侵害されたと報じられたわけでもない。

02 / 外部へ出る仕組み

本人がアプリに許可した「現在地」が出発点になる

例えば天気アプリや店舗検索アプリは、OSから位置情報を取得できる場合がある。そこに広告などのが組み込まれると、アプリの機能とは別の事業者へデータが送られる場合もある。

位置情報の利用を許可

利用者がアプリに位置情報へのアクセスを許可。これは第三者への販売に同意したこととは別です。

SDK経由の一例。今回の報道で確認された取得経路ではありません。

矢印は登場者の並びを単純化したもの。実際の送信順と送信元は各ステップに記載。SDKはスマホ内のアプリに組み込まれて動く部品であり、SDKを利用しただけで必ず位置情報を外部送信するわけではない。

03 / 氏名がなくてもなぜ危険？

同じ端末IDに「場所」と「時間」が蓄積するから

端末IDは氏名そのものではなくても、と位置・時刻の組み合わせで個人が絞られる場合がある。公開情報と照合できれば識別リスクはさらに高まる。

勤務先候補が自衛隊施設であっても、その端末の持ち主が自衛隊員と確定するわけではない。

04 / 確認できたこと・できていないこと

SDKの会社が売ったと断定できる？

報道から把握できる事実

海外のデータブローカーを通じて、国内の端末位置情報が流通。自衛隊施設に関係する移動履歴が分析対象に含まれていた。

まだ確定できないこと

収集したアプリの名前、SDKの有無、データを最初に提供した会社、個々の同意内容、各取引の違法性。

つまり、「SDKを組み込んだアプリ → SDK提供会社 → データブローカー」は起こり得る説明用モデルであって、今回の情報流出経路が判明したという意味ではない。

05 / 法律の線引き

位置情報を許可した＝売却に同意した、ではない

スマホの位置情報利用許可は、OSがアプリに現在地へのアクセスを認める操作。一方、第三者提供の適法性は、などの別のルールで決まる。

情報の状態第三者への提供で重要なこと
個人データ原則、本人の事前同意が必要。法定の例外などあり。
個人関連情報提供先が「個人データとして取得する」と想定される場合、原則として本人同意の確認などが必要。
個人と対応しない統計情報その情報だけなら、一般に個人情報保護法上の個人関連情報とは別の扱い。

位置情報が連続して蓄積され、特定の個人を識別できる場合、個人情報になり得る。氏名を消しただけで自動的に「匿名加工情報」になるわけではない。

今回の違法性は未判定。 元データの識別可能性、提供元と提供先、同意内容、外国への提供条件などの確認が必要。合法な取引でも、安全保障上の危険がなくなるわけではない。

06 / 自分でできる対策

アプリに必要な位置情報だけを渡す

01位置情報を使う理由がないアプリは、位置情報へのアクセスをオフにする。

02必要なアプリでも「使用中のみ」を検討し、不要なら正確な位置情報の提供を抑える。

03プライバシーポリシーの第三者提供・広告利用を確認し、使わないアプリを整理する。

iPhoneなら「設定 → プライバシーとセキュリティ → 位置情報サービス」からアプリ別に確認できる。位置情報をオフにしても、IPアドレスなど別の情報から大まかな位置が推測される可能性は残る。

3問で理解を確認
Q1. SDKとは、スマホに別途インストールするアプリ？

通常は違います。開発者が自分のアプリに組み込む、他社のプログラム部品・開発キットです。

Q2. 位置情報を許可すると、販売にも自動的に同意する？

いいえ。OSの位置情報許可と、企業間の第三者提供への同意は別です。

Q3. 今回の事件は「SDK企業が売った」と確定している？

いいえ。SDK経由は想定される流通モデルの一つで、具体的な収集元・最初の提供経路は未確認です。
