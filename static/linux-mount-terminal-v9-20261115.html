mount と remount の違い

mount はつなぐ。remount はつないだまま条件を変える。

※ rwでも、書き込みにはファイル権限など別の条件が関係します。

03

コマンドと実行結果

同じ touch が失敗 → 成功に変わる

前提：/dev/sdb1 は /mnt/data に ro で接続済み。十分な権限があり、ほかのエラーは発生しないとします。

$ sudo touch /mnt/data/new.txt
touch: cannot touch '/mnt/data/new.txt': Read-only file system

$ sudo mount -o remount,rw /mnt/data
$ sudo touch /mnt/data/new.txt
$ ls /mnt/data/new.txt
/mnt/data/new.txt

最初は ro で書き込みが拒否されます。remountでrwに変更すると、同じ が成功します（成功時は出力なし）。最後の ls でファイルの存在を確認します。

これは操作を理解するための模擬出力です。実機でのマウント変更は権限・利用状況などにより結果が異なります。

3問で理解を確認
mountでファイルはコピーされる？

いいえ。保存領域にあるファイルが指定したディレクトリから見えるようになります。

roの状態でtouchすると？

新しいファイルの作成は書き込みなので、roでは拒否されます。

remountで何が変わる？

接続先は変えず、ro/rwなどのマウント設定を変えられます。

コマンド・参考資料

が実際に接続されているか、 で確認できます。

findmnt -no SOURCE,TARGET,FSTYPE,OPTIONS --mountpoint /mnt/data

/ rwは OPTIONS に表示されます。
