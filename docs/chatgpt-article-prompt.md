# VIVRAS Tech｜制作ルール
**正本：** [Notion｜運営・編集方針](https://app.notion.com/p/419636f0a707814d96fcc19f422e51b3)

## 価値
SEとしての仕事を原点に、技術・教養・暮らし・経験・考察を記録する個人メディア。**学んだことを、他人が一瞬で理解できる形にする。**「Tech」は発信ジャンルの制限ではない。

## 記事の5原則
1. **冒頭1画面に結論＋俯瞰図。** 主題・構成・因果関係が10秒でつかめる。
2. **総論→各論。** 重要な前提から説明し、知らない用語や論理の飛躍を残さない。
3. **最大限短く。** 前置き、重複、抽象的な標語、用のない英語・注釈・アイコン・カードを削る。条件・例外・出典は残す。
4. **視覚で伝える。** 図、比較、余白、文字の強弱が情報そのものを説明する。操作・アニメーションは理解に役立つ場合だけ使う。
5. **初見の第三者で検証。** 「何を学べるか」「関係が分かるか」「読むべき情報が瞬時に見つかるか」をPC・375pxスマホで確認。未達なら未完成。

## 編集の順序
目的の一文 → 全体像のラフ図 → 見出しと論理構成 → 一次資料の確認 → HTML/CSS/JS → 初見レビュー → 削除・修正 → 公開・表示検証。

記事構成は原則「要点と図 → 必要な仕組み・根拠・具体例 → 留意点・出典」。**不要な章は作らず、記事ごとに最適な構成を選ぶ。** 詳しいコマンドやシミュレーションはIT記事で必要な場合に置く。体験・意見・仮説は事実と明確に区別する。

## デザイン
- [CSS Design Awards 2025 WOTY](https://www.cssdesignawards.com/blog/2025-website-of-the-year-winners/430/) の Dropbox Brand、[The Creative Website Manual](https://www.cssdesignawards.com/sites/the-creative-website-manual/48438/) など、受賞実例のタイポグラフィ・グリッド・導線を研究する。
- **受賞サイト風の装飾が目的ではない。** 視線の最短経路を作り、言葉と図が1つのメッセージに収束するように独自設計する。コード・画像の無断転載はしない。
- 安易な均一カード、青紫グラデーション、汎用アイコン、不要なアニメーションを避ける。文字の可読性、コントラスト、レスポンシブ、低モーションを維持する。

## 公開前の最低条件
- **中身：** 正確さ、一次資料、用語の前提、事実と推測の区別、著作権・会社機密・個人情報の除去。本人や家族の機微情報は明示的な許諾なしに公開しない。
- **見た目：** 冒頭10秒で主題と関係が分かる／文章が最少／375pxで横スクロールなし／リンクと操作が機能する。
- **構造：** 新規記事は `content/<slug>.html`。単体HTMLに `lang="ja"`、`title`、`description`、`category`、`published`、`../assets/site.css`、`<main>` を含める。ファイル名は英小文字・数字・ハイフン。
- **運用：** GitHubに反映後、ビルド・デプロイ・公開URL・スマホ画面を別々に確認し、未確認を成功と呼ばない。記事の修正は差分の継ぎ足しでなく完成版へ置換する。

**合格基準：** 「文章が正しい」だけでなく「見た瞬間に内容が分かる」。それまで叩き台として改稿する。

## 雇用・税制の図解ルール（2026-11-15）
- 給与総額が下がる図には**社員数×1人当たり給与**を併記し、賃下げ・解雇・労働時間減のどれが原因かを明示する。
- AI導入後に**人員削減する場合・雇用維持する場合**を区別し、売上・AI利用費・給与・利益の計算を一致させる。
- AI導入で給与由来の税収が必ず減ると断定しない。法人税と給与由来の税収を区別し、社会保険料は税金と混同しない。
- 日米の解雇規制を比較する際は米国のat-willの例外と日本の労働契約法16条を併記する。いずれも絶対的に断定しない。
- 法案の提出者・課税主体・課税標準・財源使途を一次資料で確認し、別法案や政策提言と混同しない。

## ニュース記事の主題固定（2026-11-15）
- まず「何のニュースか」「政策・法案の狙い」「誰が・何に・どう課税」を、提出者の一次資料で確定する。
- タイトルとファーストビューには必ずニュースの主題を置く。背景条件や派生問題（例：AI導入後の雇用削減・日米の解雇規制）は、主題に従属する位置にする。
- **仮説と政策目的の混同は禁止。** 例：「所得税が減り得る」は背景仮説だが、「減収の一対一補填」が法案の目的とは限らない。
- 異なる法案は、提出者・納税義務者・課税対象・税収の使い道を横並びで確認する。提言者と法案提出者も区別する。
- 図が誤解を生む場合は、見栄えより先に因果関係と課税主体を修正。既存記事のレビューでは「主題から逸れていないか」を最優先の自己検証項目にする。
